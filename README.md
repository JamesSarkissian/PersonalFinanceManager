# PersonalFinanceManager

A simple expense tracking application built with Java for my CS 193 Final Semester Project at Purdue University.

## Project Goal
The goal of this project is to create an easy way for users to track their expenses, manage transactions, and monitor their bank balance. I also hope to strengthen my Java Skills and learn how to use databases.

## MVP Scope
The application will use a Command Line Interface with the following features:
- Add or remove transactions
- View transaction history
- Track current balance
- Save transactions using SQLite

## Tech Stack
- Java - Main application logic and CLI
- SQLite - Store transaction data
- JBDC - Connect Java to SQLite

## Future Plans
- HTML/CSS Web Interface
- Spending charts and categories
- Budget Tracking
